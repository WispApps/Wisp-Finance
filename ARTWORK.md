# Artwork

## Wisp Finance app icon and promotional artwork

The Wisp Finance app icon and promotional artwork were generated using Lumo 2.0 by Proton AG.

The generation chat was deleted. The exact prompts, generation dates, and whether reference images were used are unknown.

This project includes these images as application and listing assets. The project does not claim that the generated images are unique.

The promotional images are stored in:

- docs/images/1.png
- docs/images/2.png
- docs/images/3.png
- docs/images/4.png

Promotional mockups may differ from the current app interface.
